# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. The report goes to the repository owner.

Include the version (`meridian.Version`), what you did, what you expected and what happened. Do not
include a live API key; if a key was exposed, revoke it first.

## Supported versions

This is a public preview. Only the latest release receives security fixes.
